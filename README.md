---

### What the heck is this?

Get rid of those annoying "Looks like you're using an ad blocker" messages that block your entire screen and require you to either pause them or whitelist the site you're on, both of which completely defeat the purpose of using an ad blocker.

After adding the extension to Chrome, just click the icon any time a site you're on gets all up in your business, and then you're free to continue upon said business.
